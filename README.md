# Test automation with Playwright

A free, interactive course on test automation with Playwright for manual testers who are moving into automation. Choose Python or Kotlin and switch at any moment.

Live site: https://panipanda.github.io/playwright-autotests-course/

This repository is work in progress. The README is completed together with the course content.

## Run it locally

There is no build step. Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

or any static server, for example `python -m http.server`.

## Tests

```
node --test
```
